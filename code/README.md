# 配套代码

本目录承载本书贯穿始终的**增量式 Coding Agent** 项目 `tinycode`：每章正文给出该阶段的完整代码清单（可直接誊抄运行），本目录提供可运行的项目快照。

## 当前内容

- [`tinycode/`](./tinycode/)：贯穿项目的**核心阶段**快照——第 1 部分（模型调用与 Provider 抽象）、2.1（Agent 循环与声明式并发调度）、3.x（read / write / edit / glob / grep / bash 六个核心工具）。类型检查通过，配置一个 OpenAI 兼容 API（含本地 Ollama）即可运行，见其 README。
